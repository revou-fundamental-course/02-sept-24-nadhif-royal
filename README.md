# 📏 Geometry Calculator

A simple web-based Geometry Calculator that calculates the **Area and Perimeter** of a **Triangle** and **Parallelogram**. 🧮✨

## 🚀 Features
- Calculate the **Area** and **Perimeter** of a Triangle 🔺
- Calculate the **Area** and **Perimeter** of a Parallelogram ▰
- Clear input fields easily 🔄
- User-friendly interface 🎨

## 🛠️ Technologies Used
- HTML5 🏗️
- CSS3 🎨
- JavaScript ⚡

## 📌 How to Use
1. **Select** the shape (Triangle or Parallelogram) 📌
2. **Enter** the required values 📊
3. **Click** the "Calculate" button to see the result ✅
4. **Use** the "Reset" button to clear inputs 🔄


## 🔧 Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/revou-fundamental-course/02-sept-24-nadhif-royal
   ```
2. Open the `index.html` file in your browser 🌐
